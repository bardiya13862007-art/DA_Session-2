# Iran Cities Data Visualization 📊

A beginner Python project focused on data visualization using **NumPy** and **Matplotlib**.

## About the Project

In this project, I used population and geographical data from 10 Iranian cities to practice creating different types of charts and visualizing data with Python.

## Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset includes information about 10 Iranian cities:

- City names
- Population
- Latitude
- Longitude

## Visualizations

The project includes the following charts:

- **Scatter Plot:** Displays the geographical locations of cities, with marker sizes representing population.
- **Bar Chart:** Compares the population of different cities.
- **Line Plot:** Shows population differences between cities.
- **Pie Chart:** Displays each city's share of the total population.

## Purpose

This project was created as part of my learning journey in Python and Data Analysis.
